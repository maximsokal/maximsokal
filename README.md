At the same time, I am **actively studying embedded development** and applying that learning in hands-on projects involving **C/C++, ESP-IDF, FreeRTOS, Zephyr RTOS, sensor integration, signal processing, and automated testing**.

What interests me most is the space where **creative production tools and engineering meet** — from Spine pipelines, mesh tooling, and browser-based editors to firmware, real-time data, and hardware/software integration.

## Featured projects

### 1. ESP32 Geophone Source Locator

**Embedded systems | Signal processing | ESP32-S3 | nRF54L15**

A portable, experimental seismic localization system for search-and-rescue research. It combines simultaneous multichannel ADC acquisition, distributed sensor nodes, FreeRTOS/Zephyr firmware, TFT and web interfaces, microSD logging, and 3D TDOA geometry components.

This project reflects my practical path into embedded development: not just studying theory, but building and testing a real multi-sensor system.

**Status:** Active R&D prototype. End-to-end localization accuracy is still under validation.

### 4. Re-Polish

**Spine optimization pipeline | Developer tooling | Animation technology**

[Re-Polish](https://www.re-polish.com/) is my project focused on optimizing **Spine JSON and binary `.skel` workflows** with a flexible node-based pipeline.

According to the public site, Re-Polish is designed to help with:

- reducing skeleton data size;
- atlas and texture optimization;
- keyframe and curve optimization;
- physics baking;
- whole-project Spine workflow optimization.

The public entry point is the website, and support/subscription is available through Patreon.
